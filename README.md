# AIgoRhythm

AIgoRhythm is a team project exploring an AI-assisted music improvisation experience.

## Project focus

The project examined how interface and interaction choices affect a user’s sense of presence while improvising with an AI system.

## My role

- Led the team project
- Designed the interface and interaction flow
- Conducted and analyzed user research focused on presence in human–AI musical interaction
- Coordinated the project’s design and promotion strategy

The project advanced to the final round of Duke Kunshan University’s Dachuang Innovation Incubator.

## Current status

This repository currently contains portfolio documentation only. It does not include unpublished team source code or a public working demo.
